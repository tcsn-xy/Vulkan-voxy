# Vulkan Voxy v4 / Minecraft 26.3

面向 Fabric / Java25、Apple Silicon / MoltenVK 与4GiB Java堆的远景实现。

## 本轮变化

- 网格工作集按位置和距离覆盖360°，热缓存快速转头不因朝向变化重建。
- GPU压力下逐步回收远处细分，保留当前覆盖与近处网格。
- 四边形展开流16→4字节；回退索引按需分配，预算计量含待回收资源。
- 静水顶面共用游戏当前动画纹理、染色与透明深度；雾距离和透明度遵循游戏约定。
- 当前存档刷新补齐空气区段并重建父LOD，先备份、可暂停恢复、本次探索优先。
- Vitrail0.12.0-beta + BSL10.1.5基础共存：解决通道提交崩溃并保留可见远景。远景未执行完整BSL反射/阴影/水体着色，组合下仍存在风格和颜色差异。

修复期间正式Voxy已卸载，配置、缓存和存档保留；本次只交付待安装JAR，不自动装回。性能对照由用户自行进行，不承诺未测得的FPS或GPU目标。

**本仓库仅包含独立新增组件，不能单独构建完整模组。** 修改后的上游文件、上游历史与完整JAR不公开。MIT仅适用于本仓库提供的独立新增代码，见[许可边界](UPSTREAM.md)。

[集成说明](docs/INTEGRATION.md)、[v4修复验证](docs/V4_VALIDATION.md)、[配置说明](docs/V4_CONFIGURATION.md)包含具体行为和未完成项。首次测试需自行准备合法取得的完整集成构建与Minecraft运行库。

独立纯Java辅助组件可使用Java25运行：
python3 scripts/test-primitives.py

QA脚本只写独立实例，截图和存档不随本仓库发布。隐藏渲染数据不能当作屏幕呈现FPS。本项目不实现光影包引擎，当前Vitrail基础兼容不等于完整BSL远景效果。
