# v4配置与缓存刷新

距离、分辨率及细分阈值不会被优化自动修改。阈值越小越精细，通常需要更多构建和GPU内存；冷缓存或预算不足仍可能暂时显示粗层级。朝向只影响绘制，不影响360°网格工作集。

默认预算：数据堆384MiB、CPU原生256MiB、GPU768MiB、每帧上传8MiB、两个工作线程。数组、队列、父区段引用和待GPU退休分配均受相应预算约束；它们不包含整个游戏、驱动和其他模组，不能冒充进程总物理记账。

/voxy import current refresh 是明确的当前存档刷新入口，仅限单人当前维度，源目录固定为当前存档的区域目录。它可以修复以前会话保留下来的旧地形，包括当前已变为空气的区段；当前会话中新观察的区块仍优先。
普通current/world/raw/zip导入继续保护已记录的观察数据，不会偷偷变成刷新模式。

刷新写入前在后台创建一致性RocksDB检查点：
.voxy-refresh-backups/<world-id>/<时间-UUID>/database
备份包含区段和映射，表示刷新前的磁盘缓存时间点，不是整个世界备份。单RocksDB后端支持自动检查点；其他存储配置不支持时拒绝刷新，避免无备份写入。
pause/resume/status/cancel沿用原命令，刷新与普通导入恢复游标分开。区域变化时只从首个变化的已处理区域重新处理，未变化的已完成进度保留。

恢复缓存前关闭游戏，先备份现有缓存，再用检查点database目录替换对应world-id的storage目录；保留voxy/config.json与存档本体。不要运行中复制或替换数据库。

HiZ仅使用可安全验证的历史不透明深度；相机/资源变化或可见透明几何时不会把水面深度当作实体遮挡。开关为开不保证每帧都有可用历史。

Vitrail0.12.0-beta/BSL10.1.5当前为基础共存。远景在包合成后使用近景深度绘制Voxy材质，不执行BSL远景反射/阴影/水体算法；组合下海面颜色与风格仍未完全匹配。完整BSL远景着色不在当前已通过的验收中。
