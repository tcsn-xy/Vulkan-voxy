本地集成产物 `voxy-vulkan-0.2.20-vulkan.4+mc26.3-8bc3411.jar`，SHA256 `769695af2ddc6c886302e46f780064323bd4afe4be2f905bbfe27433ff51b830`。正式 Voxy 已卸载；修复包没有自动安装回去。

## 已修复与依据

1. **转头后粗块与重建**：原工作集的细分优先级直接检查相机视锥。真实调用策略测试先失败；现在工作集按相机位置、距离和阈值准备360°地形，朝向只影响绘制。固定热缓存反复180°/360°切换，区段列表及构建次数保持不变。输入不变时也不再每50ms重新遍历整个细分树。
2. **压力下整片巨大化**：原实现压力时直接使用全部最高层根节点并清空细网格。现在逐步收缩细分前沿，保护当前区段和可用父级，按距离回收失效缓存。128MiB强制压力回归保留近处细分和完整覆盖，释放后恢复；仍不能保证超预算画质组合全精度驻留。
3. **旧缓存与当前地形不一致**：私有样本记录中，当前存档水面Y62，旧缓存仍有草地Y69；空区段被省略时，旧导入没有清除这些记录。新增当前存档刷新，以当前区域目录为唯一来源，补齐空气区段并更新所有父LOD；当前会话的探索仍优先，普通外部导入继续保护旧会话观察记录。测试验证旧记录与L0～L4全部修复、新探索保留。
4. **刷新恢复与备份**：后台在写入前创建一致性RocksDB检查点，包含区段与映射；备份失败不刷新。恢复按区域文件戳判断，保留未变化的已完成进度，对变化的已处理区域重新执行。当前存档变动不再无条件让整个任务重头开始。父区段按每工作线程最多16个/4MiB保留引用，避免每个16³输入都反复压缩同一32³父区段；这些数组计入原有预算。
5. **水面基础材质**：静水顶面改为采样游戏正在动画更新的纹理图集和采样器；保留原透明度和群系染色，不添加固定颜色补偿。透明深度写入与原版/Sodium一致，按距离排列透明区段和页。可见透明几何时不使用包含透明水面深度的历史HiZ，避免把透明水当成实体遮挡。
6. **明确的资源浪费**：每个四边形的展开流由16字节重复数据变为4字节原始索引，容量下降75%；原四边形与来源数据留在分页缓存中。默认不再分配始终闲置的12MiB索引表，按回退实际需求创建；不足时使用6顶点直接绘制回退，不改变几何。
7. **Vitrail崩溃与基础兼容**：修复上传/计算发生在已打开通道内，以及LevelPass不能转换为原前端通道的错误。准备阶段移到世界绘制图执行前，并通过Vitrail的LevelPass/GeometryHold管理通道。BSL开启时，在其合成结束后使用近景深度绘制基础Voxy远景，验证可同时显示并正常退出。

## 使用

`/voxy import current refresh` 刷新当前单人存档的当前维度。`pause/resume/status/cancel`继续适用。检查点保存在实例 `.voxy-refresh-backups/<world-id>/<时间-UUID>/database`，恢复游标保存在 `.voxy-import-state`，与普通导入分开。备份是刷新前的磁盘缓存时间点；不等同于备份整个世界。当前仅为单RocksDB后端实现自动备份，其他存储配置会拒绝刷新并报告原因。

正式存档的原缓存保持原状；以上修复验证全部在完整关闭后取得的独立副本中执行。距离、分辨率和用户细节没有被优化偷偷修改。材质诊断中的近景2区块明确仅用于定位交接，不是性能成绩。

## 实际限制与未完成项

**Vitrail当前为基础共存，不是完整BSL远景着色集成。** 近景仍有BSL水面反射/阴影/曝光，远景保留Voxy材质；组合下海面风格与颜色仍可能有明显差异。没有把“不崩溃”称为完整光影画质通过。当前验收组合限定Vitrail0.12.0-beta + BSL10.1.5，不保证其他包或未来内部接口版本。透明页间排序按距离近似，复杂跨页多层玻璃尚未逐场景验证。

用户历史巨大化截图的完整故障帧未被逐像素重现，因此不能把所有悬空归给一个根因。已修复可重现的朝向细分机制、压力全粗降级和旧缓存修复缺口，并在当前世界副本验证。冷缓存准备期间、尚未记录的地形和真正的预算压力仍可暂时显示粗层级。

没有执行长时间性能比较或一小时压测。没有宣称CPU/GPU目标、前台FPS或与NVIDIA/OpenGL的差距已达标；用户自行实机复测。4GiB仅约束Java堆，资源预算与RSS不能冒充进程总物理成本。Vitrail与驱动资源也单独存在。
